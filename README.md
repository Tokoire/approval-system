# 双端申请审批系统（Render / GitHub iPad 简化版）

这个版本专门为 iPad 网页上传 GitHub 制作：所有必要文件都在同一层，不含子文件夹。

必要文件：
- server.js
- package.json
- applicant.html
- approver.html
- styles.css
- applications.json

Render 设置：
- Language: Node
- Build Command: npm install
- Start Command: npm start
- Instance Type: Free（如页面提供）

访问：
- 申请端：/applicant.html（首页 / 也会进入申请端）
- 审批端：/approver.html
